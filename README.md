# Soberana Land Rights Monitor

Research repository for land rights monitoring. Each research topic lives in
its own folder.

- `cimi/` — research on CIMI and the Kaiowá people. Start at `cimi/README.md`:
  it holds the pipeline order, the territory-name conventions, and a table of
  every derived file and figure with the script that produces it and the
  scripts that read it.

Other research topics get a new folder at the root when started, following the
same pattern: the folder's `README.md` is the entry point, with `data/`, `docs/`
and `out/` underneath it.

A clone is large on purpose (about 170 MB) because `cimi/` version-controls its
sources — the 18 CIMI reports (2008-2025), the text extracted from them and
every figure — not only the code. The size table in `cimi/README.md` explains
each path and what it costs.
