# Derived data

Generated by the scripts in `scripts/`. Do not edit these files by hand: change
the script and re-run it. `cimi/README.md` holds the full pipeline order and the
same table with the scripts that read each file.

| File | Script | Time span of the content |
|---|---|---|
| `chapter1_conflicts.csv` | `chapter1_txt_to_csv.py` | CIMI reports 2008-2025 |
| `cimi_kaiowa_ms_conflicts.csv` | `prepare_kaiowa_dataset.py` | CIMI reports 2008-2025 |
| `cimi_kaiowa_ms_conflicts_focus_territories.csv` | `prepare_kaiowa_dataset.py` | CIMI reports 2008-2025 |
| `funai_territorial_inventory_ms.csv` | `build_funai_inventory.py` | FUNAI download retrieved 2026-11-12; legal-stage dates as published |
| `funai_kaiowa_ms_clipped.geojson` | `build_funai_inventory.py` | same as above |
| `funai_ms_territories_clipped.geojson` | `build_funai_inventory.py` | FUNAI download retrieved 2026-11-12; all 46 distinct MS territory names, with geometry. Anchor layer for the all-label bubble map. |
| `funai_focus_territories_inventory.csv` | `prepare_kaiowa_dataset.py` | same as above |
| `funai_focus_territories.geojson` | `prepare_kaiowa_dataset.py` | same as above |
| `cimi_mentions_focus_territories.csv` | `extract_territory_mentions.py` | CIMI reports 2008-2025 |
| `cimi_mentions_<slug>.csv` | `extract_territory_mentions.py` | CIMI reports 2008-2025 |
| `cimi_kaiowa_conflict_type_counts.csv` | `plot_conflict_wordcloud.py` | CIMI reports 2008-2025 |
| `mapbiomas_landcover_<ti>.csv` | `plot_mapbiomas_landcover.py` | MapBiomas Brasil Collection 11, annual 1985-2025, released 2026-08 |

`cimi_ms_occupation_shares.csv` is the one exception: it was copied by hand from
the CIMI 2020 report, which is the only edition with the complete per-territory
list, and has no producing script.

Regenerate everything, in order:

```bash
./.cimi-venv/bin/python3 scripts/chapter1_txt_to_csv.py docs/cimi-reports/txt -o data/derived/chapter1_conflicts.csv
./.cimi-venv/bin/python3 scripts/build_funai_inventory.py
./.cimi-venv/bin/python3 scripts/prepare_kaiowa_dataset.py
./.cimi-venv/bin/python3 scripts/extract_territory_mentions.py
./.cimi-venv/bin/python3 scripts/plot_conflict_heatmap.py
./.cimi-venv/bin/python3 scripts/plot_conflict_wordcloud.py
./.cimi-venv/bin/python3 scripts/plot_funai_map.py
./.cimi-venv/bin/python3 scripts/plot_conflict_bubble_map.py
./.cimi-venv/bin/python3 scripts/plot_conflict_bubble_map.py --source mentions
./.cimi-venv/bin/python3 scripts/plot_conflict_bubble_map_all.py
./.cimi-venv/bin/python3 scripts/plot_occupation_lollipop.py
./.cimi-venv/bin/python3 scripts/plot_territory_mention_timelines.py
```
